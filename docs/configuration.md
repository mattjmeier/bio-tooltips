# Configuration

Configuration is documented in shared and tooltip module-specific pages.

- [Core Reference](./reference/core.md) covers shared options such as `selector`, `prefetch`, `theme`, tooltip positioning, interaction timing, and viewport behavior.
- [Gene Configuration & Examples](./gene-configuration.md) covers display sections, ideogram settings, pathways, gene-specific counts, and live configured examples.
- [Chemical Configuration & Examples](./chemical-configuration.md) covers chemical sections, synonym/list counts, source paths, raw JSON display, optional RDKit rendering, and live configured examples.

The old `/configuration` URL remains available as this compatibility page.
